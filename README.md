## About

Lexi Book is an Android application designed for learning and reviewing vocabulary using flashcards.

It allows users to organize their vocabulary into books, folders, and flashcards, with a focus on simplicity, performance, and a clean user experience.

All user data is stored locally on the device.

## Features

* Create and manage vocabulary books
* Organize vocabulary using folders
* Create and manage flashcards
* Add meanings, pronunciations, and examples
* Review and learn vocabulary
* Easy book, folder, and flashcard management
* Clean and modern user interface
* Light and dark mode support
* Local data storage
