## درباره برنامه

Lexi Book یک برنامه اندرویدی برای یادگیری و مرور واژگان است که به شما امکان می‌دهد واژه‌های موردنظر خود را در قالب کتاب‌ها، پوشه‌ها و فلش‌کارت‌ها مدیریت کنید.

این برنامه با تمرکز بر سادگی، سرعت و تجربه کاربری مناسب طراحی شده و اطلاعات شما را به‌صورت محلی روی دستگاه ذخیره می‌کند.

## امکانات

* ساخت و مدیریت کتاب‌های واژگان
* ایجاد پوشه برای دسته‌بندی بهتر واژه‌ها
* ایجاد فلش‌کارت
* ثبت معنی، تلفظ و مثال برای هر واژه
* مرور و یادگیری واژگان
* مدیریت آسان کتاب‌ها، پوشه‌ها و فلش‌کارت‌ها
* رابط کاربری ساده و مدرن
* پشتیبانی از حالت روشن و تاریک
* ذخیره اطلاعات به‌صورت محلی
